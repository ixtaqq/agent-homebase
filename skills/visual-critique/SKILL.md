---
name: visual-critique
description: Review a rendered interface for hierarchy, usability, specificity, accessibility, and product fit.
---

Resolve the target and its intended user/task. Read existing brand guidance and inspect the rendered interface when a browser or screenshot is available. If only source is available, label visual findings as hypotheses.

Evaluate the main task first, then hierarchy, navigation, typography, spacing, contrast, content, interaction states, and responsive behavior. Ask which choices serve this particular product. Avoid aesthetic bans and invented detector scores. Separate observed functional defects from subjective recommendations.

Return the most consequential findings, with evidence and a concrete fix, plus important strengths worth preserving. If implementation was requested, fix actionable issues and verify them within that scope; do not stop at an unsolicited approval gate.

This is a lightweight local adaptation of Impeccable's design criteria, not its full runtime.
